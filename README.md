# CheckMySurf Mobile

CheckMySurf Mobile is an Expo/React Native client for reviewing beach, surf, and weather conditions. The current app lists supported beaches, shows current and forecast detail, persists a home spot and surf preferences, and retrieves data from a configured API.

## Repository map

- [`app/`](app/) — routed mobile screens
- [`components/`](components/) — surf, weather, quality, and timeline UI
- [`context/AppContext.tsx`](context/AppContext.tsx) — app state, persistence, and refresh behavior
- [`services/api.ts`](services/api.ts) — API client
